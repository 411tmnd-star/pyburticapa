# Self-Improving Skill Loop

Improve an explicit routing skill from labeled development errors, then require a separate evaluation gate before promotion.

```
python cli.py --help
```

Needs: standard library only

| File | Open it to… |
|---|---|
| [`cli.py`](cli.py) | read and run the code |
| [`dataset.py`](dataset.py) | part of the code |
| [`demo.py`](demo.py) | part of the code |
| [`promotion.py`](promotion.py) | part of the code |
| [`propose.py`](propose.py) | part of the code |
| [`skill.py`](skill.py) | part of the code |
| [`HOW_IT_WORKS.md`](HOW_IT_WORKS.md) | understand how the code is built |
| [`THEORY.md`](THEORY.md) | learn the idea behind it |
| [`LINKS.md`](LINKS.md) | quiz, diagrams, other languages, skill files, the original |
