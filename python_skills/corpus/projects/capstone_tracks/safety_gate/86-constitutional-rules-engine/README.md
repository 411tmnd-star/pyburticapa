# Capstone 86 — Constitutional Rules Engine

A rule is a name, a predicate, and an explanation. Anything missing one of those three is a vibe, not a rule.

```
python code/main.py
python code/tests.py
```

Needs: yaml

| File | Open it to… |
|---|---|
| [`code/main.py`](code/main.py) | read and run the code |
| [`code/tests.py`](code/tests.py) | run it (command above) |
| [`code/yaml_subset.py`](code/yaml_subset.py) | part of the code |
| [`outputs/`](outputs) | files the code reads or writes (kept in the course's layout) |
| [`code/rules.yml`](code/rules.yml) | a file the code uses |
| [`HOW_IT_WORKS.md`](HOW_IT_WORKS.md) | understand how the code is built |
| [`THEORY.md`](THEORY.md) | learn the idea behind it |
| [`LINKS.md`](LINKS.md) | quiz, diagrams, other languages, skill files, the original |
