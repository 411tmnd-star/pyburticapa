# Database Migration Rehearsal

Rehearse a proposed migration on a copy and show exactly what changes.

```
python cli.py samples/input.json --output demo-output
python cli.py /absolute/path/to/your-input.json --output your-output
```

Needs: standard library only

| File | Open it to… |
|---|---|
| [`main.py`](main.py) | the code |
| [`cli.py`](cli.py) | run it (command above) |
| [`presentation.py`](presentation.py) | part of the code |
| [`samples/`](samples) | files the code uses |
| [`HOW_IT_WORKS.md`](HOW_IT_WORKS.md) | understand how the code is built |
| [`THEORY.md`](THEORY.md) | learn the idea behind it |
| [`LINKS.md`](LINKS.md) | quiz, diagrams, other languages, skill files, the original |
