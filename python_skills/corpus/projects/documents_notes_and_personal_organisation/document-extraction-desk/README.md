# Document Extraction Review Desk

Extract structured fields from a text document, inspect exact source spans, and approve ambiguous values before export.

```
python cli.py sample.txt --schema schema.json --output output/review.html
```

Needs: standard library only

| File | Open it to… |
|---|---|
| [`main.py`](main.py) | the code |
| [`cli.py`](cli.py) | run it (command above) |
| [`sample.txt`](sample.txt) | a file the code uses |
| [`schema.json`](schema.json) | a file the code uses |
| [`HOW_IT_WORKS.md`](HOW_IT_WORKS.md) | understand how the code is built |
| [`THEORY.md`](THEORY.md) | learn the idea behind it |
| [`LINKS.md`](LINKS.md) | quiz, diagrams, other languages, skill files, the original |
