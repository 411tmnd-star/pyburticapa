# Streaming Answer Recovery

Reconnect a streamed answer without duplicating text or hiding an incomplete result.

```
python demo.py
node --experimental-strip-types build-browser.ts /tmp/stream-browser
```

Needs: standard library only

| File | Open it to… |
|---|---|
| [`demo.py`](demo.py) | read and run the code |
| [`cli.ts`](cli.ts) | a file the code uses |
| [`go.mod`](go.mod) | a file the code uses |
| [`HOW_IT_WORKS.md`](HOW_IT_WORKS.md) | understand how the code is built |
| [`THEORY.md`](THEORY.md) | learn the idea behind it |
| [`LINKS.md`](LINKS.md) | quiz, diagrams, other languages, skill files, the original |
