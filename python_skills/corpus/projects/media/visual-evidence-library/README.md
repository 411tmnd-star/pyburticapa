# Visual Evidence Library

Find text inside screenshots and diagrams with inspectable coordinate evidence.

```
python main.py --manifest ./fixtures/manifest.json --query "return dry seeds" --out ./visual-output
```

Needs: standard library only

| File | Open it to… |
|---|---|
| [`main.py`](main.py) | read and run the code |
| [`demo.py`](demo.py) | part of the code |
| [`fixtures/`](fixtures) | files the code uses |
| [`HOW_IT_WORKS.md`](HOW_IT_WORKS.md) | understand how the code is built |
| [`THEORY.md`](THEORY.md) | learn the idea behind it |
| [`LINKS.md`](LINKS.md) | quiz, diagrams, other languages, skill files, the original |
