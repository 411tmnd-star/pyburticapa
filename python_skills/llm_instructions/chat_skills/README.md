# Claude chat skills

Copies of the skills saved to the Claude chat account, kept here so the instructions are documented with the code they drive. These are **chat** skills: they assume Claude chat's tools and limits (for example, chat cannot open X links). Claude Code skills are separate and live in `.claude/skills/` on the laptop; the course's skill files are in `../skills/`.

The account copy is the one Claude chat uses. To change a skill, change it in chat (the skill proposal card), then copy the new SKILL.md here. In these copies, private chat links are replaced by the artifact's name.
