# Breakdown

Take a design down to the minimum: where it appears, what is said over it, the HTML and CSS, the motion timing, the workflow that made it. Then build an original the same way.

## Five steps

1. **Capture** (see [../intake/](../intake/)).
2. **Timestamp.** Transcribe, match to the transcript, read any on-screen scrubber; state the accuracy.
3. **Rebuild the generic.** Templates, landing pages, slides: a faithful HTML/CSS rebuild, one standalone page each, plus an anatomy table (below).
4. **Break down the distinctive.** Artworks, ads, films are not cloned: shot list, timings, tools seen, what makes version 1 worse than the final, then an original made with the same method.
5. **Go further.** Repos that push past what was shown, with licence ([../references/DESIGN_REPOS.md](../references/DESIGN_REPOS.md)).

## Crit sheet

[crit.html](crit.html): one OVERALL line, then lettered fixes A, B, C pinned to exact spots on the image; "same note as A" instead of repeating; go one level deeper than a customer would look. Load your own image; copy the result out as Markdown. Notes are saved in your browser only.

## Rules

- Write the brief before the code, and follow [../principles/](../principles/).
- Labels on everything: verified here, source claim, our inference, unchecked.
- Never reproduce someone else's artwork, ad, logo or product design.
- End every breakdown with a "Not checked" list.
