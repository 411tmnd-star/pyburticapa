How it's built

  1. Seeded recursion. A branch splits into 2–3 children with random angle and length. A fixed seed means the "same" tree every play.
  2. Two trees, one cut. Phase 1 is a compact tree with a depth limit of 7. Phase 2 is a wider, deeper tree (depth 9, wider angles, longer arms) that grows from 0 to full length in 10 s, branch by branch in order of depth.
  3. Pruning. In phase 1, a third of the leaves are flagged at random. From 6–9 s each flagged leaf detaches, falls with gravity and a sine drift, and fades.
  4. Ease. Growth uses an ease-out per branch, staggered by depth, so the tree swells rather than ticks.
